Обработка сетевых ошибок и завершение потоков в PyQt6

1. Какие изменения внесены
Добавлена обработка сетевых ошибок в ReceiveThread
Добавлен сигнал disconnected для передачи информации об отключении
Добавлена проверка ситуации, когда recv() возвращает None
В MainWindow добавлен обработчик handle_disconnected()
Добавлен индикатор состояния подключения
В SendThread добавлен метод stop() для остановки потока

2. Как обрабатывается потеря соединения
В ReceiveThread добавлена обработка сетевых ошибок с помощью try/except
Если соединение потеряно или сервер закрывает соединение, отправляется сигнал disconnected
В MainWindow этот сигнал обрабатывается методом handle_disconnected()
Пользователь получает уведомление, а отправка сообщений блокируется

3. Как организована остановка SendThread
Для остановки потока используется специальное значение None, которое помещается в очередь методом stop()
Когда SendThread получает None, он завершает цикл
При закрытии окна вызывается stop(), затем закрывается сокет и приложение ожидает завершения обоих потоков

4. Какие проверки выполнены
Проверена отправка сообщений между двумя клиентами
Проверено подключение к серверу
Предусмотрена проверка отключения сервера и изменения индикатора состояния
